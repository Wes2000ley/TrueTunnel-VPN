# TrueTunnel 3.1.0

The modern Windows desktop is now available as a normal release. This release
removes the preview suffix from the application, executable metadata and package
names. Its VPN engine, cryptographic policies and dependencies are unchanged
from 3.1.0-preview.1.

## Download and run

Download **TrueTunnel-3.1.0-windows-x64.zip** from the
[GitHub release](https://github.com/Wes2000ley/TrueTunnel-VPN/releases/tag/v3.1.0).
Extract the entire ZIP into its own directory, then open `TrueTunnel.exe`.
Keep the supplied `wintun.dll` next to it. Do not run the application from
inside the ZIP or mix its files with an older release.

- Windows 11 or Windows Server 2022 or newer, x64.
- Microsoft Edge WebView2 Evergreen Runtime is required for the GUI. Windows 11
  normally includes it; this ZIP does not install it. If missing, obtain the
  runtime from [Microsoft](https://developer.microsoft.com/microsoft-edge/webview2/).
- Node.js, npm, .NET, OpenSSL, and a separate Visual C++ Redistributable are not
  runtime prerequisites for this build.
- Opening the GUI does not require Administrator privileges. Starting a tunnel
  requests UAC approval for a separate native worker under the same Windows
  user. Elevation using another administrator's credentials is not supported.
- `TrueTunnel.exe` is not Authenticode-signed. Windows may display an unknown
  publisher or reputation warning. Checksums verify file integrity, not
  publisher identity; do not disable Windows protections.

## Modern desktop and native networking

- Embedded React/TypeScript interface hosted in WebView2, with aligned
  connection controls, responsive cards, light/dark/system themes, accessible
  dialogs, keyboard navigation, searchable activity, and reduced-motion support.
- Unelevated interface and on-demand elevated network worker. Access keys stay
  in native memory, outside JavaScript, JSON and the DOM. Local control messages
  are bounded and checked against process identity.
- Native Schannel TLS 1.3 / wolfSSL DTLS 1.3 engine, optional heartbeat/reconnect,
  deterministic Wintun identity, TCP session renewal and UDP traffic-key updates.
- Embedded frontend assets and pinned dependencies, with no runtime development
  server. Conan, ImGui and FreeType are not part of the active build.

See the [changelog](../../CHANGELOG.md) for the work since V3. Use matching
versions at both ends; this release does not establish compatibility with older
V3 binaries or other VPN protocols.

## Validation and known limitations

The release's `VALIDATION.md` records the source revision, build commands,
observed test results and package checks. Native transport/IPC/lifecycle tests,
the headless frontend/axe matrix and the actual EXE's unelevated rendering test
are distinct from an elevated real-network VPN test.

**Still pending for this desktop release:** elevated real-Wintun TCP/UDP E2E;
actual GUI Connect/Start server/Disconnect/tray qualification across the new
privilege boundary; fresh real-tunnel throughput, latency and renewal-gap
measurements; RRAS/NAT Internet sharing; and clean-machine installation.
Normal-release publication does not mean these unrun checks passed. See
[the full test matrix](../TESTING.md).

Other boundaries remain: IPv4 only; a shared group credential without per-peer
revocation; no kill switch, DNS-leak policy, seamless roaming, or signed automatic
updater. There is no independent security audit or FIPS validation. Evaluate
these limitations before a security-critical deployment. See
[Security design](../SECURITY-DESIGN.md).

## Integrity and source

`SHA256SUMS.txt` covers the downloadable artifacts and the extracted EXE/DLL.
Compare your ZIP with:

```powershell
Get-FileHash .\TrueTunnel-3.1.0-windows-x64.zip -Algorithm SHA256
```

The accompanying source archive includes the exact TrueTunnel revision, pinned
wolfSSL source, JSON header, WebView2 SDK, and frontend source/lockfile inputs.
The default binary statically links open-source wolfSSL and is distributed
under its GPLv3 terms; TrueTunnel-authored code uses the MIT option in `LICENSE`.
Third-party terms remain in `NOTICE`, `THIRD_PARTY.md`, and `licenses/`.
